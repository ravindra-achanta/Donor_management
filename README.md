# Vikas Web App

Overview

Vikas Web App is a production-focused Flutter application engineered
for multi-platform delivery (Android, iOS, Web, macOS, Windows,
Linux). The codebase emphasizes modularity, testability, and clear
separation of concerns: presentation (views/widgets), state
management (BLoC), and data access (API services and repositories).
This makes the project easy to extend, maintain, and integrate with
backend services.

## Key Features

- Multi-platform: single codebase for mobile, web, and desktop targets
- Modular architecture: distinct modules for `api_services`,
	`bloc_management`, `views`, and `widgets` to simplify development
	and testing
- Networked data layer: centralized API/repository pattern with
	unified error handling and caching support
- Predictable state management: BLoC-based flows for testable UIs
- Persistence & offline support: local storage for tokens, prefs,
	and cached data
- Localization & theming: multi-language support and pluggable
	themes (see `lib/localizations/` and `lib/themes/`)
- Reusable components: a widget library for consistent UI and faster
	feature development
- CI/CD and deployment ready: includes `Jenkinsfile`, `Dockerfile`,
	and `nginx.conf` for automated builds and web hosting

## Prerequisites

- Install Flutter (stable channel). Recommended: Flutter 3.0+.
- Android SDK and Android Studio (for Android builds and emulators).
- Xcode (for iOS builds) on macOS.
- A modern browser (for web development/testing).

Verify Flutter setup:

```bash
flutter --version
flutter doctor
```

## Getting Started (local development)

1. Clone the repository:

```bash
git clone <repo-url>
cd vikas-web-app
```

2. Fetch dependencies:

```bash
flutter pub get
```

3. Run on a device/emulator:

- Android emulator or connected device:

```bash
flutter run -d android
```

- iOS (macOS with Xcode):

```bash
flutter run -d ios
```

- Web (Chrome):

```bash
flutter run -d chrome
```

## Build

- Build APK:

```bash
flutter build apk --release
```

- Build iOS (macOS):

```bash
flutter build ios --release
```

- Build web bundle:

```bash
flutter build web --release
```

## Project Structure (high level)

- `lib/` — core Dart code: entrypoint, controllers, services, views, widgets
- `assets/` — images, fonts, and other static assets
- `android/`, `ios/`, `macos/`, `windows/`, `linux/`, `web/` — platform
	projects generated by Flutter
- `test/` — unit and widget tests
- `Jenkinsfile`, `Dockerfile`, `nginx.conf` — CI/CD and deployment

## Configuration

- API endpoints and constants live in `lib/api_services/`.
- Local dev keys and `local.properties` for Android should be added
	locally (do not commit secrets).

## Testing

Run unit and widget tests with:

```bash
flutter test
```

## CI / Deployment Notes

- This repo includes a `Jenkinsfile` for CI. Adjust pipeline steps as
	needed for your environment.
- `Dockerfile` and `nginx.conf` are provided for serving the web
	build in a containerized environment.
